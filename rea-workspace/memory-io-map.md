# SPC-1000 Hardware Memory & I/O Architecture Specification

## 1. 개요
본 문서는 SPC-1000 원본 바이너리(`spc1000.rom`) 및 에뮬레이터 레퍼런스(`reference/meeso-spc1000/`)를 역공학 및 분석하여 정립한 SPC-1000 하드웨어 아키텍처 및 버스 타이밍 명세서이다.

---

## 2. 메모리 아키텍처 (Memory Map)

SPC-1000은 64KB의 RAM과 32KB의 IPL/Hu-BASIC ROM을 내장하고 있으며, `IPLK` 플립플롭 신호에 의해 뱅크 스위칭된다.

| 주소 영역 | IPLK = 1 (부팅 초기 모드) | IPLK = 0 (All RAM 모드) | 메모리 쓰기 동작 |
| :--- | :--- | :--- | :--- |
| `0x0000 - 0x7FFF` (32KB) | **ROM** (IPL / Hu-BASIC) | **RAM** (0x0000 - 0x7FFF) | 항상 **RAM**에 쓰기 (Shadow RAM) |
| `0x8000 - 0xFFFF` (32KB) | **RAM** (0x8000 - 0xFFFF) | **RAM** (0x8000 - 0xFFFF) | 항상 **RAM**에 쓰기 |

- **부팅 상태:** 전원 투입/리셋 시 하드웨어에 의해 `IPLK = 1`로 초기화되어 `0x0000` 번지의 ROM 리셋 벡터(`C3 00 FB`)부터 실행 시작.
- **섀도우 RAM 특징:** ROM이 활성화된 상태(`IPLK = 1`)에서 `0x0000 ~ 0x7FFF` 영역에 데이터를 기록하면 ROM 아래에 가려진 RAM에 저장되므로, 뱅크 스위칭 후 곧바로 RAM 코드를 실행할 수 있음.

---

## 3. I/O 포트 매핑 (16-bit I/O Space)

SPC-1000은 Z80의 16비트 I/O 포트 어드레싱(`BC` 레지스터 기반 `IN r, (C)` / `OUT (C), r`)을 상위 비트 디코딩과 함께 활용한다.

### 3.1. VRAM 포트 (`0x0000 - 0x1FFF`, 마스크 `Port & 0xE000 == 0x0000`)
- **주소 공간:** `0x0000 - 0x1FFF` (실제 6KB VRAM + 속성 버퍼)
- **읽기:** `InZ80(Port)` -> VRAM 데이터 반환
- **쓰기:** `OutZ80(Port, Value)` -> VRAM에 데이터 저장 및 비디오 화면 갱신 트리거

### 3.2. VDG 디스플레이 제어 (`0x2000 - 0x3FFF`, 마스크 `Port & 0xE000 == 0x2000`)
- **레지스터:** Motorola MC6847 모드 제어 (`GMODE`)
- **쓰기:**
  - `Bit 3 (0x08)`: `1` = 그래픽 모드(Semigraphics/High-res), `0` = 텍스트 모드
  - 기타 비트: MC6847 `A/G`, `A/S`, `INV`, `CSS`, `GM0~GM2` 제어핀에 직결
- **읽기:** 현재 설정된 `GMODE` 바이트 반환

### 3.3. 사운드 칩셋 AY-3-8910 PSG (`0x4000 - 0x5FFF`, 마스크 `Port & 0xFFFE == 0x4000`)
- **`Port 0x4000` (Write):** PSG 레지스터 인덱스 선택 (`0 ~ 15`)
- **`Port 0x4001` (Write):** 선택된 PSG 레지스터에 데이터 기록
- **`Port 0x4001` (Read):**
  - 만약 선택된 레지스터가 **14번(Port A)**인 경우: **카세트 테이프 읽기 신호**(`CasIORead`) 반환
  - 기타 레지스터: PSG 레지스터 값 반환

### 3.4. 카세트 테이프 제어 (`0x6000 - 0x7FFF`, 마스크 `Port & 0xE000 == 0x6000`)
- **쓰기:** 카세트 모터 온/오프 및 테이프 기록 펄스(FSK 신호) 제어
  - `Bit 0`: 테이프 모터 릴레이 (`1` = On, `0` = Off)
  - `Bit 1`: 오디오 출력 펄스 토글

### 3.5. 키보드 매트릭스 스캔 (`0x8000 - 0x8009`)
- **주소:** `0x8000` ~ `0x8009` (총 10개 행)
- **읽기:** 해당 행에 연결된 8개 키의 눌림 상태(비트맵, Active-High) 반환

| 포트 | Bit 7 | Bit 6 | Bit 5 | Bit 4 | Bit 3 | Bit 2 | Bit 1 | Bit 0 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| `0x8000` | - | GRAPH | - | BREAK | - | CTRL | SHIFT | - |
| `0x8001` | '1' | 'Q' | 'A' | 'C' | RET | SPACE | HOME | '~' |
| `0x8002` | '2' | 'W' | 'S' | 'V' | ']' | 'Z' | - | CAPS |
| `0x8003` | '3' | 'E' | 'D' | 'B' | '[' | ESC | - | DEL |
| `0x8004` | '4' | 'R' | 'F' | 'N' | '\\' | '→' | - | - |
| `0x8005` | '5' | 'T' | 'G' | 'M' | - | '←' | F1 | - |
| `0x8006` | '6' | 'Y' | 'H' | ',' | 'X' | '@' | F2 | - |
| `0x8007` | '7' | 'U' | 'J' | '.' | 'P' | '↑' | F3 | - |
| `0x8008` | '8' | 'I' | 'K' | '/' | ':' | '↓' | F4 | - |
| `0x8009` | '9' | 'O' | 'L' | ';' | '0' | '-' | F5 | - |

### 3.6. IPLK 뱅크 토글 (`0xA000 - 0xBFFF`, 마스크 `Port & 0xE000 == 0xA000`)
- **동작:** 해당 I/O 주소로 읽기(`IN`) 또는 쓰기(`OUT`) 명령이 발생할 때마다 `IPLK` 플립플롭이 즉시 반전 (`IPLK = !IPLK`)

## 4. 인터럽트 및 타이밍 구조
- **CPU 클럭:** Z80A @ 4.000 MHz (사이클당 약 250ns)
- **수직 동기 인터럽트 (VBLANK / Timer):**
  - MC6847의 `/FS` (Field Sync) 핀이 Z80의 `/INT` 핀에 연결됨 (60Hz 주기)
  - Z80 인터럽트 모드: **Mode 1** (`IM 1`)
  - 벡터 주소: `0x0038` -> ROM 내 핸들러 `0x0074`에서 `(0x0036)` 카운터 증가 처리
